# Healthcare Sales ML Project

## Project Overview
This project focuses on analyzing healthcare sales data using Python and Machine Learning techniques to identify business insights and predict sales trends.

The project includes:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
- Machine Learning Model Building
- Sales Prediction

---

## Business Problem
Healthcare companies generate large amounts of sales data across hospitals, pharmacies, and healthcare providers. The objective of this project is to analyze sales patterns and build predictive models that help improve business decision-making.
